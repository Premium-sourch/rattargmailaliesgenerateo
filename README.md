# Gmail Alias Generator

A free, open-source Gmail alias generator that runs entirely in the browser — no backend, no tracking, no data sent anywhere.

## Features

- **12 variation types**: Dot variations, Plus tags, Googlemail domain, Dots + Googlemail, Custom +tags, Underscores, Number suffixes, Leet speak, Repeated letters, Case variations, Dots + Plus combo, Name rearrangement
- Select any combination or all at once
- Search, filter by type, and sort results
- List and grid view
- Star/save your favourite aliases
- Copy all to clipboard or download as CSV
- Mobile-first design (max 600px), dark mode support
- Zero dependencies — pure HTML, CSS, JavaScript

## Deploy to Vercel (free)

1. Push this folder to a GitHub repository
2. Go to [vercel.com](https://vercel.com) → New Project
3. Import your GitHub repo
4. Click **Deploy** — done!

## Deploy to GitHub Pages (free)

1. Push this folder contents to a GitHub repo
2. Go to repo **Settings** → **Pages**
3. Set source to **main branch / root**
4. Your site will be live at `https://yourusername.github.io/repo-name`

## Run locally

Just open `index.html` in any browser — no server needed.
